Bahman AI - rclone-server2

A private, single-user backup tool of the Bahman AI organization.

What the application does

rclone-server2 is a personal backup tool. It copies encrypted restic backups of a server that belongs to the owner of this organization into the owner's own Google Drive, reads them back when a backup has to be verified or restored, and removes backups that have expired. The transfer is performed by rclone using this OAuth client.

Who uses it

The application is used only by its owner. It is not offered to the public, has no other users and does not provide sign-up.

Google data

The application accesses Google Drive only to store and read the owner's own encrypted backup files. Backup data is encrypted by restic before it leaves the server, so the files in Google Drive cannot be read without the owner's key. No Google user data is shared with third parties.
