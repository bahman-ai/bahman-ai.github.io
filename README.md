# bahman-ai.github.io

Public GitHub Pages site of the Bahman AI organization.

It hosts only the home page and the privacy policy of the private backup
OAuth application `rclone-server2`, as required by Google for a published
OAuth consent screen:

- Home page: https://bahman-ai.github.io/
- Privacy policy: https://bahman-ai.github.io/privacy.html

This repository is public and must never contain secrets, personal data,
internal paths, addresses or host names. Its content is published by the
Access Agent fixed route `access_agent.github_pages_site_route` from
`sites/bahman-ai.github.io/` of the Access Agent repository; edit it there.
