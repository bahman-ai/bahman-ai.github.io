Privacy Policy

Application: rclone-server2 (Bahman AI). Effective date: 2026-11-06.

1. Scope

rclone-server2 is a private backup tool used only by its owner. It is not offered to other people and has no other users.

2. Google data the application accesses

With the owner's consent the application uses the Google Drive API to write, read and, when old backups expire, remove the owner's own encrypted backup files (created by restic) in the owner's own Google Drive. It does not access any other files and does not use Google data for any other purpose.

3. How the data is used

The data is used only to store backups of the owner's server and to verify or restore them. Backup content is encrypted before upload; the application does not analyze it and does not use it for advertising, profiling or training of any models.

4. Sharing

Google user data is not sold, transferred or disclosed to third parties.

5. Data of other people

The application does not collect personal data of any other users.

6. Storage and security

The OAuth credentials of the application are kept in the owner's secret manager and are never published. Backups remain in the owner's Google Drive under the owner's control.

7. Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. After revocation the application can no longer access Google Drive.

8. Limited Use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

9. Contact and changes

Questions can be raised through the bahman-ai organization on GitHub. Changes to this policy are published on this page.
